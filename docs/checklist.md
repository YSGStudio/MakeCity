## Acceptance Criteria

- [x] AC1 3초 안에 바다 마을이 보이고 콘솔 오류가 없다
- [x] AC2 세 탭마다 다른 지형과 지형 이야기 문구가 보인다
- [x] AC3 산·들 마을에서는 항구를 짓지 못하고 이유 문구가 뜨며, 바다 마을의 바닷가에는 지어진다
- [x] AC4 평지에는 논, 비탈에는 계단식 밭이 생기고 힌트가 한 번 뜬다
- [x] AC5 해금 전 시설은 🔒 표시가 나오고, 해금 연도에 기록이 남는다
- [x] AC6 도로 옆이 아닌 칸의 도시 시설은 "도로 옆에만" 문구로 막힌다
- [x] AC7 강 위 도로는 다리 모형으로 지어지고 비용은 40이다
- [x] AC8 5년 지나기 12번 → 2030년 결과 창, 그래프 점 13개
- [x] AC9 세 마을 자동 발전이 오류 없이 끝나고, 인구 순서가 들 > 바다 > 산, 들 마을 환경 50 이상
- [x] AC10 비교 창에 3개 마을 열, 시설 18종 행, 3선 그래프가 있다
- [x] AC11 탭을 바꿔도 마을별 진행이 유지되고, 다시 시작은 보던 마을만 되돌린다
- [x] AC12 폭 800px에서 정보 패널이 숨겨지고 📋 버튼으로 열고 닫힌다
- [x] AC13 들 마을 인구 80명 이상·학교 없음이면 학교 안내 기록이 남는다
- [x] AC14 새로고침해도 연도·인구·예산·건물·미션·기록이 그대로 돌아오고 불러오기 알림이 뜬다
- [x] AC15 localStorage에 마을별 JSON 키가 있고 50KB 이하이며, 외부 저장 요청이 없다
- [x] AC16 다시 시작은 확인 창을 거쳐 해당 마을 키만 지운다
- [x] AC17 저장이 막히거나 값이 깨져도 오류 없이 진행되고 "⚠️ 저장 안 됨"이 보인다
